---
title: DEX Calldata Decoding
description: Decode Uniswap router calldata to typed structs, zero-copy and zero-panic.
---

eth.zig decodes swap calldata from major DEX routers without allocations, panics, or RPC calls. The `decode` function recognizes UniswapV2Router02, V3 SwapRouter, SwapRouter02, and the Universal Router, returning a typed union over the calldata or `null` for unknown selectors and malformed input.

## Guarantees

- No allocation. All paths, arrays, and command inputs are views that borrow the input calldata. They remain valid only while the calldata itself is valid.
- No panics on hostile input. Malformed or truncated calldata returns `null` instead of failing.
- All validation is upfront. A non-null result means every field accessor and iterator is infallible.
- Calldata only. The function reads only the call data and returns no transaction context. Callers must verify `tx.to` against a known router address.

## Decode a Call

```zig
const eth = @import("eth");

const decoded = eth.dex.decode(tx.data) orelse return;
switch (decoded) {
    .v2_swap_exact_tokens_for_tokens => |swap| {
        std.debug.print("v2 in={d} min_out={d} hops={d}\n", .{ swap.amount_in, swap.amount_out_min, swap.path.len() - 1 });
    },
    .v3_exact_input_single => |swap| {
        std.debug.print("v3 {x} -> {x} fee={d}\n", .{ swap.token_in, swap.token_out, swap.fee });
    },
    else => {},
}
```

## Examples

### V2: Exact Input Swap

```zig
const decoded = eth.dex.decode(tx.data) orelse return;
switch (decoded) {
    .v2_swap_exact_tokens_for_tokens, .v2_swap_exact_tokens_for_eth => |swap| {
        std.debug.print("{x} -> {x}: in={d} min_out={d}\n", .{
            swap.path.first(), swap.path.last(), swap.amount_in, swap.amount_out_min,
        });
    },
    else => {},
}
```

### V3: Multi-Hop Path

```zig
const decoded = eth.dex.decode(tx.data) orelse return;
if (decoded == .v3_exact_input) {
    const swap = decoded.v3_exact_input;
    for (0..swap.path.hops()) |i| {
        const hop = swap.path.hop(i);
        std.debug.print("hop {d}: {x} -> {x} fee={d}\n", .{ i, hop.token_a, hop.token_b, hop.fee });
    }
    std.debug.print("in={d} min_out={d}\n", .{ swap.amount_in, swap.amount_out_minimum });
}
```

Exact-output V3 paths are encoded in reverse. For `v3_exact_output`, `path.first()` is the token out and `path.last()` is the token in.

### SwapRouter02: Multicall

Most SwapRouter02 traffic wraps its swap in `multicall`. Inner swaps decode to the same `Decoded` union. Other inner calls, such as `selfPermit` or `unwrapWETH9`, come back raw.

```zig
const decoded = eth.dex.decode(tx.data) orelse return;
if (decoded == .multicall) {
    var it = decoded.multicall.iterator();
    while (it.next()) |call| switch (call) {
        .swap => |inner| std.debug.print("swap: {s}\n", .{@tagName(inner)}),
        .other => |raw| std.debug.print("call {x}, {d} bytes\n", .{ raw.selector, raw.data.len }),
    };
}
```

### Universal Router: Commands

Each command carries its raw byte, the `allow_revert` flag, and a typed payload. Command types without a typed payload, such as `V4_SWAP` and the Permit2 commands, arrive as `.other` with their raw input.

```zig
const decoded = eth.dex.decode(tx.data) orelse return;
if (decoded == .universal_router_execute) {
    var it = decoded.universal_router_execute.iterator();
    while (it.next()) |cmd| switch (cmd.payload) {
        .v3_swap_exact_in => |swap| std.debug.print("v3 in={d} hops={d}\n", .{ swap.amount_in, swap.path.hops() }),
        .v2_swap_exact_in => |swap| std.debug.print("v2 in={d} len={d}\n", .{ swap.amount_in, swap.path.len() }),
        .wrap_eth => |wrap| std.debug.print("wrap {d}\n", .{wrap.amount}),
        .other => |raw| std.debug.print("type 0x{x:0>2} revert_ok={} {d} bytes\n", .{ raw.command_type, cmd.allow_revert, raw.input.len }),
        else => {},
    };
}
```

## Not Covered

The decoder does not handle:

- V4 swap action plans or nested commands in Universal Router.
- Permit2 signatures and permit payloads (not part of swap calldata).
- Inner calls within `multicall` that are not recognized swaps (returned as `.other`).
- DEX routers beyond V2 forks that share the Uniswap ABI, such as 1inch or curve routers.
